# Guac frontend

From the repository root, run `npm ci --prefix frontend`, then `npm --prefix frontend run dev`. Node24.12.0 was verified; Vite7 supports Node20.19+ or22.12+. Development listens on127.0.0.1:5174 with strict port; `/api` proxies to127.0.0.1:8001. Start the independent FastAPI backend as documented in root README. Production check: `npm --prefix frontend run build`. Deterministic tests: `npm --prefix frontend test`.

Vue owns presentation and explicit navigation. controllers/exerciseClock.js owns monotonic active time,4/6 phase and smooth balloon inflation; no model text controls an exercise. controllers/sessionPersistence.js owns per-session queues and optimistic versioned storage, retaining offline operations until explicit retry. Every5seconds updates active elapsed; reload may lose up to5seconds of elapsed. Startup backend marks active/paused rows interrupted. Pending unsaved records only exist in this visit and can be lost on reload, honestly displayed. controllers/chatController.js owns generation/stale guards and request identity. Grounding optional notes remain component-local, clear each step, and never reach storage/model.

Contracts: GET `/api/health`; POST `/api/conversations` ->id; POST `/api/conversations/{id}/messages` `{request_id,text}` ->status/mode/messages/result with reflection/recommended_skill/reason/optional clarification/action; GET conversations/detail/sessions; POST sessions `{request_id,skill,conversation_id?,recommendation_request_id?}` ->versioned row; PATCH session `{version,state,active_elapsed_ms,step,cycles,skipped_steps}`; GET/PATCH/DELETE preferences; DELETE history. Preferences are explicit_balloon_color avocado/red/sage/blue/plum ornull, simple_view, reduced_motion. Conversation reset clears UI only. History deletion is confirmed and removes records, retaining preferences.

HTTP200 chat `failed` is an outcome, not success: user message is visible with failure label; no assistant text invented. Finite25second chat deadline permits backend20second timeout; other API uses8seconds. Cancel/navigation ignores stale responses. Repeated pending send/start ignored. API error boundary never displays raw provider payloads. Failed retries use same request_id so the backend deduplicates; a new input starts a new request. Current mode labels distinguish mocks/live and unknown health. Guac uses conversation-first layout with direct exercises, an original code-native SVG avocado, and Peel/Leaf/Flesh/Lime/Cream/Pit tokens. Null explicit color uses avocado green; saved earlier colors are preserved. Browser keyboard inset uses visualViewport where available but requires real-device verification. Default host model mode is mock and live-call limit is backend enforced.

SupportPanel is bundled and independent of model/backend. Fixed footer access is always reachable, keyboard dialog traps/restores focus; opening pauses exercise. Bounded explicit-phrase offer is not risk assessment and can miss indirect text or match quoted fictional language. Support remains available regardless of match. Coursework fictional scenarios only; no monitoring or deployment.
